# Pomeranian Toys – pomeraniantoysofficial.com

Statični sajt (bez builda) za Pomeranian Toys by Darija Paspalj / ATK Company, Banja Luka.

- `index.html`, `style.css`, `app.js` – sajt (BS/EN)
- `config.js` – Supabase URL, anon ključ i admin email
- `supabase.sql` – šema baze (tabele `stenci`, `galerija`, `admini`, bucket `slike`)
- `img/usluge/` – slike usluga (grooming.jpg, seminari.jpg, hotel.jpg, cuvanje.jpg, prevoz.jpg, ozon.jpg)

Admin panel: link "Admin" u futeru ili `#admin` na kraju adrese.
